# DumpIdItem

DumpIdItem exports mappings from legacy numeric item IDs to Axolotl-PM items. It scans IDs from `-214` through `511` and metadata values from `0` through `50` when the server starts.

## Requirements and compatibility

- Axolotl-PM API 5.0.0 or newer within the 5.x API series. The [build workflow](.github/workflows/build.yml) records exact tested source revisions. Compatibility with every 5.x release has not been verified.
- PHP 8.1 or newer, as required by Axolotl-PM 5.

## Installation and output

Download the PHAR from [GitHub Releases](https://github.com/NhanAZ-Plugins/DumpIdItem/releases), place it in the server's `plugins` directory and restart the server. No command or configuration is required.

The plugin writes two files in its server data folder on each start:

| File | Contents |
|---|---|
| `out1.txt` | One line for each distinct runtime item state ID found in the scan. |
| `out2.txt` | One line for each distinct item description found in the scan. |

Each line begins with the legacy `id:meta` input followed by the resolved item description. The committed [out1.txt](out1.txt) and [out2.txt](out2.txt) are historical examples. Use files generated by the server revision you are investigating. Runtime state IDs and legacy mappings can change between releases. This scan does not enumerate every modern item.

The two files in the server data folder are replaced on each start. Keep copies of output you need to compare across server versions.

## Development and validation

The [build workflow](.github/workflows/build.yml) tests distinct output records against pinned Axolotl-PM source revisions. It uses [DevTools](https://github.com/NhanAZ/DevTools) to run PHPStan at maximum level, build the PHAR and inspect the artifact. Exact tested revisions and results are available in [GitHub Actions](https://github.com/NhanAZ-Plugins/DumpIdItem/actions).

The output fixture checks duplicate handling. A runtime smoke test of a release PHAR checks the full startup scan. Results from one server version should not be treated as a compatibility claim for every Axolotl-PM 5.x release.
